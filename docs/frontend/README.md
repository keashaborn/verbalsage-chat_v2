# Frontend Design Documentation

These documents govern visual and interaction work across Verbal Sage and LifeSwitch:

- [`WEB_DESIGN_STANDARD.md`](./WEB_DESIGN_STANDARD.md) — approved universal design decisions and the review checklist for new pages.
- [`UI_CSS_AUDIT_METHOD.md`](./UI_CSS_AUDIT_METHOD.md) — the required method and evidence format for site-wide frontend audits.

New frontend work should use the design standard before implementation. Audits and redesign proposals should cite the relevant rule rather than introducing page-specific preferences without explanation.
